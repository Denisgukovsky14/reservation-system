# DesignHub

Платформа-агрегатор подрядчиков: заказчик находит исполнителя (дизайнера, мастера по мебели на заказ и др.), договаривается с ним, ведёт проект и оставляет отзыв. Учебный проект, который я довожу до рабочего состояния.

## Что умеет

- **Два типа пользователей**: заказчик и подрядчик, у каждого свой профиль
- **Каталог подрядчиков**, портфолио и прайс-лист услуг
- **Сделки**: проект проходит по этапам от запроса до завершения
- **Чат** между заказчиком и подрядчиком внутри сделки
- **Отзывы** и уведомления
- **3D-рабочий стол** (`/3Dtable`): интерактивный модуль на фронтенде. Пока живёт отдельно и не связан с авторизацией

## Стек

| Слой | Технологии |
|---|---|
| Backend | Java 17, Spring Boot 4, Spring Web, Spring Data JPA (Hibernate) |
| База данных | PostgreSQL |
| Безопасность | Spring Security, BCrypt, JWT |
| Frontend | HTML / CSS / JS (статика, раздаётся самим Spring) |
| Сборка и тесты | Maven, JUnit 5 |

## Как устроено

```
Браузер  →  Controller  →  Service  →  Repository  →  PostgreSQL
              (REST)      (логика)    (Spring Data)     (Entity)
```

- **Controller** принимает запрос и отдаёт JSON, **Service** содержит логику, **Repository** работает с базой.
- **Entity** описывает таблицу, **DTO** то, что уходит клиенту. Пароль в DTO никогда не попадает.
- Страницы фронтенда лежат в `src/main/resources/static/src/pages`.

```
src/main/java/com/designhub/
├── Controllers/   REST-эндпоинты (/api/auth, /api/deals, /api/messages ...)
├── Services/      бизнес-логика
└── Tables/        Entity, Repository и DTO по каждой таблице
```

## Безопасность

- Пароли хранятся только в виде **BCrypt-хэша**.
- При входе выдаётся **JWT-токен**, фронтенд прикладывает его ко всем запросам.
- Все эндпоинты, кроме входа, регистрации, главной страницы и статики, требуют токен.
- Изменить можно только **свой** профиль: id из токена сверяется с id в запросе (защита от IDOR).
- Без токена сервер отвечает `401`, на чужой ресурс `403`.

## Как запустить

1. **PostgreSQL** на порту `5434`, например в Docker:
   ```bash
   docker run --name postgres-designhub -e POSTGRES_PASSWORD=designhub -p 5434:5432 -d postgres
   ```
2. **Приватные данные.** Скопируй `src/main/resources/application-local.properties.example` в `application-local.properties` и впиши пароль от базы и свой `jwt.secret` (base64, не менее 256 бит). Этот файл в `.gitignore`.
3. **Запуск:**
   ```bash
   ./mvnw spring-boot:run
   ```
4. Открой http://localhost:8080
